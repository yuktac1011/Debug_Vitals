Follow these steps in order. Copy the IDs from each response into the next step.

Step 1 — Ingest Events
POST /api/v1/events
Use any payload from the “Event Payloads” tab.
Save the session_id from your payload — you’ll use it in every subsequent step.
Step 2 — View Timeline
GET /api/v1/session/{session_id}/timeline
Verify all events were ingested in chronological order.
Step 3 — Run Diagnosis
POST /api/v1/session/{session_id}/diagnose
Body: {"top_n": 5, "include_graph": false}
Save the returned id (diagnosis UUID) for steps 4 and 5.
Step 4 — Verify (optional)
POST /api/v1/session/{session_id}/verify
Body:
{"docker_image":"python:3.11-slim","command":"python -c \"import sys; sys.exit(1)\"","diagnosis_id":"<uuid>"}
Step 5 — Regression Guard
POST /api/v1/session/{session_id}/regression-guard
Body:
{"diagnosis_id":"<uuid>","top_n_causes":3,"docker_image":"python:3.11-slim","run_immediately":false}

Copy any payload below into Swagger › POST /api/v1/events › Request body.

POST /api/v1/session/{session_id}/diagnose — Request body:

{
  "top_n": 5,
  "include_graph": false
}

With graph (larger response):

{
  "top_n": 10,
  "include_graph": true
}

POST /api/v1/session/{session_id}/verify — Request body:

{
  "docker_image": "python:3.11-slim",
  "command": "python -c \"print('sandbox OK'); import sys; sys.exit(0)\"",
  "environment": {},
  "diagnosis_id": null
}

Reproduce a failure:

{
  "docker_image": "python:3.11-slim",
  "command": "python -c \"raise RuntimeError('reproduced failure')\"",
  "environment": {"MY_VAR": "test"},
  "diagnosis_id": null
}

POST /api/v1/session/{session_id}/regression-guard — Request body:

{
  "diagnosis_id": "<paste diagnosis UUID here>",
  "top_n_causes": 3,
  "docker_image": "python:3.11-slim",
  "run_immediately": false,
  "language": "python"
}

Generate AND run immediately:

{
  "diagnosis_id": "<paste diagnosis UUID here>",
  "top_n_causes": 2,
  "docker_image": "python:3.11-slim",
  "run_immediately": true,
  "language": "python"
}
